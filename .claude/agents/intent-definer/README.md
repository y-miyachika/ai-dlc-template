# Intent Definer SubAgent

AI-DLC準拠のインテント定義専門SubAgent

## 概要

ユーザーの曖昧な要望を、明確で実行可能なインテント定義に変換するSubAgentです。

**AI-DLC原則**: 会話の逆転（AIが質問を主導し、人間が回答する）

## 特徴

### 1. 対話型の明確化

4つの質問でインテントを明確化：

1. **主要なユーザーは誰ですか？**
2. **どのようなビジネス成果を達成したいですか？**
3. **制約条件はありますか？**
4. **成功の定義は何ですか？**

### 2. 構造化されたドキュメント生成

AI-DLC準拠の詳細なインテント定義を生成：

- インテント概要
- ステークホルダー分析
- ユーザーストーリー（As a/I want/So that形式）
- 受入基準（BDD形式: Given/When/Then）
- 非機能要件（NFR）
- リスクレジスター
- 成功指標（定量的・定性的）
- 制約条件、依存関係

### 3. 測定可能な受入基準

すべての受入基準は：

- 具体的で測定可能
- テストで自動検証可能
- ユーザーが価値を実感できる

## 使い方

### AI-DLCテンプレート内で使用

```bash
/intent <要望の概要>
```

### 他プロジェクトで使用

このSubAgentは、AI-DLCテンプレート以外のプロジェクトでも利用可能です：

1. `.claude/agents/intent-definer/` をコピー
2. プロジェクトに配置
3. SubAgentを呼び出し

## 処理フロー

```
1. 既存インテントの確認
   ↓
2. 4つの質問で明確化
   ↓
3. インテント定義の生成
   ↓
4. レビューと確認
   ↓
5. ユーザー承認
   ↓
6. ファイル保存（docs/intents/）
```

## 生成されるファイル

```
docs/intents/
├── 001_ユーザー認証機能.md
├── 002_REST_API最適化.md
└── 003_CI_CD自動化.md
```

**ファイル名**: `{連番}_{タイトル20文字以内}.md`

## AI-DLC原則との対応

| 原則 | 実装方法 |
|-----|---------|
| **会話の逆転** | AIが4つの質問を主導し、人間が回答 |
| **損失関数** | 曖昧さを早期解消し、下流の無駄な作業を防ぐ |
| **コンテキストメモリ** | 詳細なインテント定義を永続化 |
| **段階的詳細化** | インテント → ユニット → ドメイン → コード |
| **トレーサビリティ** | 成功指標とユーザーストーリーの対応を明確化 |

## SubAgent vs Skill

**なぜSubAgentなのか**:

- **対話型プロセス**: 4つの質問でユーザーと対話し、曖昧さを解消
- **多段階思考**: 回答を統合し、構造化されたドキュメントを生成
- **コンテキスト保持**: 前の回答を踏まえて次の質問を調整

**Skillとの違い**:

| 項目 | Skill | SubAgent |
|-----|-------|----------|
| **実行形式** | 単発処理 | 対話型・多段階 |
| **用途** | コード生成など | 要件定義など |
| **再利用性** | 高（独立） | 高（独立） |
| **思考の深さ** | 浅い | 深い |
