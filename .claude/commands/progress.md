# プロジェクト/パッケージの現状確認

指定されたパッケージ（または全体）の現状を確認し、サマリーを表示します。

## 引数
- パッケージ名（省略時は全体）
- 例: `collector`, `api`, `shared-domain`, `infrastructure`

## 実施内容

### 1. Git状況の確認
```bash
git status
git log --oneline -5
```

### 2. TaskList APIによる現在の進捗確認（優先）

`TaskList`（v2.1.16+）を呼び出し、現在のセッションのタスク状態を確認する。
**TaskListが利用できない場合（v2.1.16未満）は、この手順をスキップしてステップ3に進む。**

```
TaskList → 全タスクのid, subject, status, owner, blockedByを取得
```

**表示形式**:
```markdown
### 現在のタスク状況（TaskList）
| # | タスク | ステータス | ブロッカー |
|---|--------|-----------|-----------|
| 1 | ドメイン層実装 | ✅ completed | - |
| 2 | インフラ層実装 | 🔄 in_progress | - |
| 3 | API層実装 | ⏳ pending | #2 |
```

TaskListにタスクがない場合は、この手順をスキップする。

### 3. 実装計画の進捗確認
- `docs/intents/*/*/plan.md` 配下の実装計画を読み込む
- 進捗状況（完了/進行中/未着手）をサマリー表示
- ブロッカーがあれば強調表示

### 4. テスト状況の確認（オプション）
- 最新のテスト実行結果があれば表示

## 出力形式

```markdown
## {パッケージ名} ステータス

### Git状況
- ブランチ: main
- 変更ファイル: X件
- 最新コミット: {hash} {message}

### 実装進捗
| フェーズ | ステータス |
|---------|-----------|
| Phase 1 | ✅ 完了 |
| Phase 2 | 🟡 進行中 |
| Phase 3 | ⏳ 未着手 |

### 現在のタスク状況（TaskList）
| # | タスク | ステータス | ブロッカー |
|---|--------|-----------|-----------|
| 1 | {タスク名} | ✅ completed | - |
| 2 | {タスク名} | 🔄 in_progress | - |

### ブロッカー
🔴 {ブロッカー内容}

### 次のアクション
- {推奨アクション}
```

## 注意事項
- 実装計画ファイルが存在しない場合はその旨を表示
- 複数パッケージを一度に確認する場合はサマリー形式で表示
