# ブロッカーの記録

実装計画にブロッカー（障害・課題）を記録します。

## 引数
- パッケージ名（必須）
- ブロッカーの概要（必須）
- 例: `/blocker collector IAM作成権限がない`

## 実施内容

### 1. 実装計画ファイルの特定
- `packages/{パッケージ名}/docs/plans/` 配下の最新実装計画を読み込む

### 2. ブロッカーセクションの追加/更新
以下の形式でブロッカーを記録：

```markdown
## ブロッカー

### 🔴 {ブロッカー概要}（{日付}）

**問題**: {詳細な問題説明}

**影響範囲**:
- {影響1}
- {影響2}

**必要なアクション**:
- [ ] {アクション1}
- [ ] {アクション2}

**回避策（検討中）**:
- {回避策1}
- {回避策2}
```

### 3. 対話形式で情報収集
1. 問題の詳細説明
2. 影響範囲
3. 必要なアクション
4. 回避策（あれば）

### 4. 実装計画の更新
- 「次のステップ」セクションに🚧マークを追加
- ブロッカーセクションを追加/更新

## 出力形式

```
✅ ブロッカーを記録しました

📍 ファイル: packages/{パッケージ名}/docs/plans/{計画ファイル}
🔴 問題: {概要}
📅 日付: {日付}

コミットしますか？
```

## 注意事項
- 実装計画ファイルが存在しない場合はエラー
- 既存のブロッカーセクションがあれば追記
- ユーザーの確認を得てからコミット
