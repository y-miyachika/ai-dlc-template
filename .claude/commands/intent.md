## SubAgentについて

`intent-definer` SubAgentは、対話型プロセスでユーザーの要望を明確化し、構造化されたインテント定義に変換する専門SubAgentです。

**AI-DLC原則**: 会話の逆転（AIが質問を主導し、人間が回答する）

詳細は `.claude/agents/intent-definer/README.md` を参照してください。

## AI-DLCにおけるインテントとは

**インテント（Intent）**は、ビジネス目標、機能、または技術的な成果（例：パフォーマンスのスケーリング）など、達成すべきことをカプセル化する高レベルのステートメントです。

これは、AI駆動の分解を実行可能なタスクに行い、人間の目標とAI生成の計画を調整するための出発点として機能します。

以下を実行します：

1. **既存インテントの確認**: `docs/intents/` ディレクトリを確認し、連番を採番
2. **4つの質問で明確化**: AIが質問を主導し、ユーザーが回答
3. **インテント定義の生成**: AI-DLC準拠の詳細なドキュメントを生成
4. **レビューと確認**: ユーザー承認を得る
5. **ファイル保存**: `docs/intents/{番号}_{Intent名}/intent.md` に保存

## SubAgentの4つの質問

SubAgentは以下の質問を行います（**会話の逆転**）：

1. **主要なユーザーは誰ですか？**
   - 開発者、デザイナー、エンドユーザー、プロダクトオーナー、その他

2. **どのようなビジネス成果を達成したいですか？**
   - 開発効率の向上、品質改善、新機能の提供、技術的負債の解消、コスト削減、等

3. **制約条件はありますか？**
   - 時間制約（デッドライン）
   - 技術的制約（既存システムとの互換性）
   - リソース制約（トークン制限、メモリ制限）
   - 依存関係（他チームの成果物に依存）

4. **成功の定義は何ですか？**
   - 測定可能な指標（定量的）
   - 例: 「ビルド時間が10秒以内」「エラー率が1%未満」「ユーザー満足度80%以上」

## SubAgent処理の詳細

SubAgentは `.claude/agents/intent-definer/prompt.md` に定義された手順に従って処理を実行します。

**主要な処理**:

1. 既存インテントの確認（連番採番）
2. 4つの質問で要望を明確化
3. ユーザーストーリーの生成（As a/I want/So that形式）
4. 受入基準の生成（BDD形式: Given/When/Then）
5. NFR、リスク、成功指標の定義
6. ユーザー承認を得る
7. `docs/intents/{番号}_{Intent名}/intent.md` に保存

**テンプレート詳細**: `.claude/agents/intent-definer/prompt.md` を参照

## AI-DLC原則との対応

| 原則 | 実装方法 |
|-----|---------|
| **会話の逆転** | AIが4つの質問を主導し、人間が回答 |
| **損失関数** | 曖昧さを早期解消し、下流の無駄な作業を防ぐ |
| **コンテキストメモリ** | 詳細なインテント定義を永続化 |
| **段階的詳細化** | インテント → ユニット → ドメイン → コード |
| **トレーサビリティ** | 成功指標とユーザーストーリーの対応を明確化 |
